# Agent Team Backlog

Both Claude and Gemini pull from this list. Rules:
- Each worker picks the FIRST task that is not `[x]` and not `[~]`.
- Mark `[~]` while working, `[x]` when done, then git commit.
- Write tasks so they are small, verifiable, and safe.

## Tasks
- [x] Example: read the repo and write a NOTES.md summarizing what the project does
- [x] Example: add tests for the module with the least coverage
- [x] Example: fix any failing tests and commit the fix
